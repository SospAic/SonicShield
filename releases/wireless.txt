# 无线设备接入列表 —— 每行一个 host:port
# 以 # 开头的行会被 install_all.bat 忽略。
#
# 支持的行格式（install_all.bat 会识别）：
#   <host:port>              直接 adb connect（设备已配对 / Android < 11）
#   pair <host:port> <配对码>  先 adb pair（Android 11+ 首次无线配对，配对码有时效）
#   mdns                     自动 adb mdns services 并连接所有发现的无线设备
# 注意：Android 11+ 是「先配对、再连接」，配对端口与连接端口不同，通常成对写入
#       「一行 pair + 一行裸 host:port」。示例见文末。
#
# 如何拿到 host:port ：
#   1) 手机需已开启「无线调试」（开发者选项）
#   2) 在电脑上执行：  adb mdns services
#      会列出形如：  adb-960f853-Kmi5Mk  _adb-tls-connect._tcp  192.168.0.173:34199
#      把最后的 192.168.0.173:34199 抄到下面即可。
#   3) 或让手机在「无线调试」页显示 IP:端口，用  adb pair 先配对、再写入。
#
# 示例（取消注释并改成你的实际地址）：
#   mdns
#   pair 192.168.1.5:39999 123456        （配对端口 + 手机「无线调试」页生成的 6 位配对码）
#   192.168.1.5:37939                    （连接端口，配对成功后写入）
