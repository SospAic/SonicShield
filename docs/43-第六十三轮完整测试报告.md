### 3.1 本轮踩到的三个坑（首跑实测红，已修）

1. 🔴 **`device_info_plus` 的通道方法名是 `getDeviceInfo`，不是 `getAndroidDeviceInfo`**：
   通道名 `dev.fluttercommunity.plus/device_info` 正确，但方法名写错 ⇒ 桩抛 `MissingPluginException`
   ⇒ 被 `_detectVendor` 的 `on Object` 兜底吞掉 ⇒ 悄悄退回 `'generic'`（症状是"找不到文本"，根因在方法名）。
2. 🔴 **`debugDefaultTargetPlatformOverride` 必须在**用例体内**复位**：放进 `addTearDown` 会晚一步 ——
   框架在**用例体结束后、tearDown 之前**就跑 `debugAssertAllFoundationVarsUnset`
   ⇒ 报 `The value of a foundation debug variable was changed by the test.`。修法 = `try { ... } finally { ... = null; }`。
3. 🔴 **删文件的链不能以"文件已消失"为退出条件**：`_deleteAsset` 先删记录、再（异步）删文件、**最后才 `setState`**；
   文件被 OS 删掉是**同步可见**的（`existsSync()` 立刻为 false），但 Dart 侧 `await f.delete()` 的**续体**要等
   下一次 pump 才恢复 ⇒ 早退会在 `setState` 之前收工，列表不刷新（断言只看到旧的 `'A'`）。
   修法 = **固定轮数**（真实事件循环转一圈 + 排空 fake 微任务，机制见 `sound_library_screen_test.dart` 文件头 §二）。

## 五、本轮发现并修复的真实漂移（算术过期）
