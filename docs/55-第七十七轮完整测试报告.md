## 二、两条新基线落地

### 2.1 新基线「每次迭代 APP 显示版本必须同步更新」

- **问题**：`AppMeta.version` 只锁 `x.y.z[-pre]`，而每次迭代抬的是**构建号** `+N` —— 若界面只显示
  `version`，用户看不出本轮已更新（设置页「关于」历史上还长期写死 `v1.0.0`）。
- **实现**：
  - `lib/core/constants.dart`：`AppMeta.buildNumber = '18'`；新增 `static String get displayVersion => '$version+$buildNumber';`（`version = '1.9.0-alpha'`）。
  - `pubspec.yaml`：`version: 1.9.0-alpha+18`。
  - 设置页「关于」：改为从 `AppMeta.displayVersion` 取，**禁写死版本字面量**。
- **机器锁（`test/version_consistency_test.dart`，`version` 组 4 → 6）**：
  ① 「`buildNumber` == pubspec `+N`」；② 「设置页含 `displayVersion` 且无写死版本字面量」。
- **长期规则**：每轮改版本 = **同时改** `constants.dart` 的 `version`/`buildNumber` + `pubspec.yaml`，
  否则 `version` 组判红（已写入 `HANDOVER.md` ★ 新增长期规则）。

### 2.2 反击计划生成参数化

- **参数模型**：新增 `lib/domain/models/counter_plan_params.dart`（schema `sonicshield.counterPlanParams/1`）。
  - `PlanWindowParams`：`enabled` / `volumeMin`·`volumeMax` / `durationSecMin`·`durationSecMax` /
    `actionsPerHourMin`·`actionsPerHourMax`；上界 `maxDurationSec`（= `CounterWindow.maxDurationSec`，600）与
    `maxActionsPerHour`（12）；`clamped()`（越界夹紧、min>max 交换） / `fromJson(raw, fallback)` / `toJson()` /
    `copyWith(...)`（内部已 `.clamped()`） / `describe()` / `validateInto(...)`。
  - `CounterPlanParams`：`dayStartHour`·`dayEndHour` / `cooldownSecMin`·`cooldownSecMax` / `respectQuietHours` /
    `workdayDay`·`workdayNight` / `restdayDay`·`restdayNight`（默认 `enabled: false`） / `presetIds` / `ttsTexts` / `voiceId`；
    `defaults()` / `windowFor(DayKind, {required isNight})` / `anyEnabled` / `fromJson`（**永不抛**） / `toJson` /
    `clamped()` / `validate()`（用**原始非夹紧值**，错误文案含「schema 不匹配」「动作间隔区间下限/上限」
    「音量区间必须在 0–1」「时长区间必须在 1–600 秒」「每小时次数区间必须在 0–12」「TTS 文案过长」）/ `isValid` /
    `summary()` / `toPromptHint()`。
- **设置页 UI**：新增 `_PlanParamsDialog`（`lib/features/settings/settings_screen.dart`）——
  只使用 `RangeSlider` + `SwitchListTile`（**无 `TextField`**，避免导出/加密用例 `find.byType(TextField).at(0)` 假红）：
  - 顶部「时段与间隔」：白天时段（0–23）/ 动作间隔（秒）（0–2400）+ 「遵循免打扰时段」开关；
  - 「工作日」：白天 / 夜间两段；「休息日（可选）」：白天 / 夜间两段；
  - 每段在 `enabled` 时展开三条区间：**音量** / **时长** / **每小时次数**，全部可调；
  - 三按钮：`恢复默认` / `取消` / `保存`。
- **同源**：本机随机（`counter_plan_random.dart`）与 AI 提示词（`deepseek_service.dart` 经 `toPromptHint()`）
  使用同一套参数，本地 / 远程一致。
