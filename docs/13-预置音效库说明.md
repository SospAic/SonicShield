# 13 · 预置音效库说明

> 位置：`assets/audio/presets/*.wav` + `assets/audio/presets_manifest.json`
> 生成器：`tool/gen_sfx.dart`（`dart run tool/gen_sfx.dart` 一键重建）

---

## 1. 法律属性（重要）

**全部 78 条音效均为程序化合成**（物理声学建模 + 固定随机种子），
不含任何录音采样素材——无第三方版权、无肖像/声音权风险、可复现可审计。
真实录音扩展（CC0 资源包）见 docs/11 v1.1-A。

## 2. 目录与清单

## 4. 合成技术

| 技术 | 应用 |
|---|---|
| 冲击模态合成（strike/mode synthesis） | 敲击/撞击/玻璃/铃/金属——一组模态频率经高 Q 谐振器 + 指数衰减 |
| 共振峰合成（formant synthesis） | 人声近似/狗吠/猫叫/鸡鸣——基频谐波激励过 2–3 个共振峰 |
| 统计噪声（白/粉/棕） | 助眠底噪、雨风基底、摩擦成分 |
| 滤波链（一阶 LP/HP + 双二阶谐振器） | 频段整形、闷响（隔壁声）、金属 ringing |
| 幅度/频率调制 | 拖拽节奏、雨滴分布、鸟鸣啁啾、警报扫频 |
| **带通噪声爆**（`noiseBurst`，二阶滤波 + 毫秒级衰减） | 玻璃/瓷器"炸开"的那一下——刺耳感来自 2–8kHz 能量 + 快衰减 |
| **碎片群**（`debris`，随机时刻/模态的脆响簇） | 碎玻璃、碎瓷的"沙沙叮当"；前密后疏模拟真实落地 |
| **金属尖啸**（`screech`，非整数倍谐波 + 砂砾层） | 刹车尖啸、铁器刮擦；谐波取 2.02/3.07 倍才有"毛刺"感 |

## 5. 刺耳度实测（2026-10-28）

`_pt/sfx_spectral.py`（纯标准库手写 FFT，不依赖 numpy）对**全段分帧、按帧能量加权**
算频谱重心与 2–10kHz 能量占比。后者是「刺耳」的客观代理：人耳等响曲线在 3–4kHz
最敏感，能量落在这一带才真的"扎耳朵"，而不是单纯音量大。

| 文件 | 频谱重心 | 2–10kHz 占比 | 过零率/s |
|---|---|---|---|
| `glass_shatter`（既有，对照） | 4988 Hz | 90.8% | 6147 |
| `harsh_glass_smash` | 7215 Hz | 75.9% | 6714 |
| `harsh_plate_smash` | 7448 Hz | 83.9% | 7005 |
| `harsh_furniture_crash` | 6710 Hz | 78.9% | 3566 |
| `harsh_metal_crash` | 3796 Hz | 57.0% | 1096 |
| `harsh_glass_grind` | 6992 Hz | 81.6% | 11122 |
| `harsh_nails_blackboard` | 3511 Hz | 86.9% | 6353 |
| `harsh_metal_screech` | 4806 Hz | 93.9% | 5943 |
| `harsh_drill` | 4362 Hz | 61.2% | 3161 |

`nails_blackboard`（3.5kHz）与 `metal_screech`（4.8kHz / 93.9%）正落在最刺的等响区；
`metal_crash` 重心偏低是**故意的**——金属板的模态本来就在 180–2650Hz，
靠高 Q 长余韵而不是高频取胜。

### 两条实测踩坑（已修，原因写在生成器注释里）

1. **碎片模态超过 0.45×SR 会混叠**：`resonator` 的 `cos(2πf/SR)` 在 f > SR/2 时
   不报错，而是把能量折到混叠频率上。修前 `harsh_glass_smash` 的 2–10kHz 占比
   只有 **23.9%**（能量全糊在 10kHz 以上，手机小喇叭放不出、听感变"嘶"），
   给模态加上限过滤后升到 **75.9%**。
2. **`emit` 默认 8ms 淡入会削掉瞬态峰值**：`harsh_metal_crash` 的"砸"峰值落在
   前 1.3ms 内，归一化到 0.9 后被淡入削到 0.34。`harsh` 类改用 1.5ms 淡入。

## 6. 再生成与扩展

```bash
dart run tool/gen_sfx.dart     # 固定种子 seed=20260913，输出完全可复现
```

新增音效：在 `main()` 中按分类追加 `emit(category, id, name, desc, samples)`
（用既有合成原语组合），重跑生成器并重新打包。清单由生成器自动维护。

⚠️ **新增条目必须追加在 `main()` 末尾**（当前在 `annoy` 之后、`manifest` 之前）：
生成器用**全局固定种子** `_rng`，在中间插入会改变其后所有条目的随机序列 ⇒
既有 wav 会**字节级变化**（听感可能变、diff 巨大）。追加在末尾则前 N 条逐字节不变
——本轮 78 条里前 70 条的 SHA256 与改动前完全一致，可作自证。
