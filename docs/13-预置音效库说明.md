# 13 · 预置音效库说明

> 位置：`assets/audio/presets/*.wav` + `assets/audio/presets_manifest.json`
> 生成器：`tool/gen_sfx.dart`（`dart run tool/gen_sfx.dart` 一键重建）

---

## 1. 法律属性（重要）

**全部 60 条音效均为程序化合成**（物理声学建模 + 固定随机种子），
不含任何录音采样素材——无第三方版权、无肖像/声音权风险、可复现可审计。
真实录音扩展（CC0 资源包）见 docs/11 v1.1-A。

## 2. 目录与清单

| 项 | 值 |
|---|---|
| 数量 | **60 条**（12 分类 × 5 变体） |
| 规格 | 22050 Hz · 单声道 · 16bit PCM（总体积约 5.5MB） |
| 清单 | `presets_manifest.json`（id/分类/名称/描述/文件/时长） |
| 导入 | 音源库页右上角「导入预置库」→ 拷入应用私有目录并入库（带 `预置/<分类>` 标签，幂等） |
| 试听 | 列表条目播放按钮（PlaybackService 试听，8s 上限） |

## 3. 分类明细（12 类 × 5）

| 分类 | 音效 |
|---|---|
| knocks 敲击 | 敲门（单下/三连）、敲桌、急促指关节、敲窗 |
| impacts 撞击 | 重物落地、柜门碰撞、球体弹跳、书本摔落、隔壁闷响 |
| drags 拖拽 | 拖椅子（短/长）、拖箱子、地板刮擦、桌面推物 |
| doors 门窗 | 开门吱呀、关门砰、锁扣、门铃（叮咚）、拧门把手 |
| glass 玻璃陶瓷 | 玻璃轻碰、玻璃碎裂、杯放桌面、瓶盖、瓷碗磕 |
| human 人声近似 | 咳嗽、清嗓、喷嚏、叹气、短促招呼（合成人声） |
| animals 动物 | 狗吠（低沉/清脆）、猫叫、鸟鸣（婉转）、公鸡打鸣 |
| bells 提示铃 | 自行车铃、风铃、机械闹钟、上课铃、钟磬 |
| alarms 警示 | 电子哔、警报扫频、倒计时哔、防火警报、蜂鸣器 |
| nature 自然 | 雨声、暴雨、雷声、风声、海浪 |
| tech 电子 | 消息提示、键盘敲击、手机振动、鼠标点击、设备提示 |
| ambient 助眠 | 白噪音、粉噪音、棕噪音、雨夜、风扇 |

## 4. 合成技术

| 技术 | 应用 |
|---|---|
| 冲击模态合成（strike/mode synthesis） | 敲击/撞击/玻璃/铃——一组模态频率经高 Q 谐振器 + 指数衰减 |
| 共振峰合成（formant synthesis） | 人声近似/狗吠/猫叫/鸡鸣——基频谐波激励过 2–3 个共振峰 |
| 统计噪声（白/粉/棕） | 助眠底噪、雨风基底、摩擦成分 |
| 滤波链（一阶 LP/HP + 双二阶谐振器） | 频段整形、闷响（隔壁声）、金属 ringing |
| 幅度/频率调制 | 拖拽节奏、雨滴分布、鸟鸣啁啾、警报扫频 |

## 5. 再生成与扩展

```bash
dart run tool/gen_sfx.dart     # 固定种子 seed=20260913，输出完全可复现
```

新增音效：在 `main()` 中按分类追加 `emit(category, id, name, desc, samples)`
（用既有合成原语组合），重跑生成器并重新打包。清单由生成器自动维护。
