# 04 · 调度引擎与随机化设计

> 对应实现：`lib/domain/scheduling/schedule_engine.dart`（纯函数）
> `lib/core/utils/random.dart`（确定性随机）`lib/services/background_engine.dart`（执行宿主）

---

## 1. 核心概念

```
Task（任务定义）
   │  materialize(now, horizon=48h)
   ▼
PlannedEntry（未来计划，含执行参数：音量/时长在物化期敲定）
   │  幂等提交
   ▼
occurrences 表（唯一事实源，状态机 pending→done/failed/skipped）
   │  executeDue()（双通道入口）
   ▼
runAction() → Playback / TTS / Notify / Record / Vibrate → exec_logs
```

**物化（materialize）**：把任务定义翻译成未来 48h 内的具体触发时刻。
引擎每小时左右滚动一次（剩余 pending < 12h 时续算），保证计划窗口始终
覆盖未来一天以上。原生精确闹钟按物化结果同步排布。

## 2. 六种触发的物化算法

| 类型 | 算法 |
|---|---|
| fixedOnce | `[at]` 若落在 [now, now+H] 内 |
| dailyAt | 视界内每天生成 `time` 时刻；可选 dateRange 过滤 |
| weeklyAt | 视界内逐日判断 ISO 星期 ∈ weekdays |
| randomWindow | 对 dateRange 每一天：窗口 [windowStart, windowEnd(+1d if 跨午夜)] 内均匀抽样 timesPerDay 个时刻，相邻间隔 ≥ minGap；窗口起点被 now 截断 |
| randomInterval | 对每天：活动窗口内首点随机（当日窗口均分 1/maxPerDay 内），此后按 [minGap, maxGap] 均匀推进，maxPerDay 封顶 |
| soundTriggered | 不进时间计划，由守卫服务实时驱动 |

## 3. 确定性随机（DPRNG）

```dart
int planSeed(String taskId, DateTime localDate) {
  // FNV-1a 32bit: hash("$taskId|$dayKey")，dayKey = yyyy-MM-dd
}
```

- 每天每任务一个 seed：同日重算结果逐位一致（幂等）；
- 跨日/跨任务 seed 不同：不同任务的随机时刻不会相关联；
- 时长/音量在物化期用同一 rng 派生并**写入 occurrence 行**，
  形成「计划即审计」——任何时候可以回答"为什么 9 月 13 日 14:37 以 63% 音量响了 8 秒"。

**抽样算法 `sampleInWindow`**：n 个点、窗口 W、最小间隔 g。
若 (n-1)·g > W 自动退化为等分+四分之一抖动；否则拒绝采样
（上限 n·200 次），失败兜底等分。结果升序返回。

## 4. 免打扰与护栏（物化期强约束）

- 免打扰窗口支持跨午夜（默认 22:00–07:00）。对任一触发时刻构造两个
  候选窗口（今晚/昨晚），命中即按策略处理：
  - `skip`：丢弃该条目；
  - `shift`：平移到免打扰结束点；**结束点已过期则直接放弃**
    （防止休眠唤醒后风暴式补执行）。
- 冷却：物化后按相邻间隔 ≥ max(task.cooldown, 60s) 去尾；
  执行期再次校验（声音触发多任务共享守卫时防串扰）。
- 音量上限 100%、冷却下限 60s 为编译期常量（`ComplianceGuardrails`），
  UI/配置不可绕过。

## 5. 执行语义

1. **陈旧丢弃**：逾期 > 10 分钟的计划标记 skipped（Doze 唤醒后的
   补执行只处理"刚过期"的条目；catchUpLimit=3 兜底上限）；
2. **幂等**：两通道同时唤醒不会重复执行——occurrence 状态机 + 主键去重；
3. **失败闭环**：动作异常写 exec_logs(status=failed) 并通知用户；
4. **任务禁用/删除**：物化自然过滤；删除级联清理 occurrences。

## 6. DST 与时区

v1 以本地时区墙钟时间定义计划（用户语义："每天 10:00"）。DST 跳变日
（我国无 DST，海外用户 v2 支持）以墙钟优先，物化不重复不丢失，
极端场景（凌晨 1–3 点的触发）允许 ±1h 偏差并记录于日志。
v2 路线图引入 `timezone` 库做严格 TZ 语义。

## 7. 验收用例（单测已覆盖，41 例中的 14 例）

| 用例 | 断言 |
|---|---|
| planSeed 稳定性 | 同任务同日相同；跨日/跨任务不同 |
| sampleInWindow | n 个点、间隔 ≥ minGap、全部落在窗口内 |
| pickWeighted | 大样本频率 ≈ 权重比（±3%） |
| dailyAt 物化 | 48h 视界内正确条数、升序 |
| randomWindow 幂等 | 两次物化逐位一致；落在窗口内；同日间隔 ≥ minGap |
| 免打扰 skip | 窗口内条目被丢弃 |
| 免打扰 shift | 平移至次日免打扰结束点 |
| fixedOnce 过期 | 不生成 |
| 冷却 | 相邻条目间隔 ≥ 冷却 |
| 声音触发 | 不进时间计划 |
| 禁用任务 | 不生成 |
