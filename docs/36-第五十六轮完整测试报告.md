### 2.3 ⚠️ 本轮新踩的坑：「中继静默死亡」

**现场**：首次启动设备作业后约 8 分钟，计划任务**提前结束**：

- `Get-ScheduledTask` 回到 `Ready`，`LastTaskResult=1`，**`.done` 从未写出**；
- `_pt/bf1run.txt` 只有 **570 字节**（停在第一个文件表头），但 `_pt/bf1_app_smoke_test.txt` 已完整 `All tests passed!`；
- 第二个集成文件的输出文件**根本没被创建**；无 `bash` / `dart` / `timeout` 残留进程（`java` = Gradle daemon 仍在）。

**逐条排除（只认现场）**：

| 嫌疑 | 实测 | 判定 |
|---|---|---|
| 中继通路本身坏了 | 冒烟作业 `_pt/jobBF0.sh` → `_pt/bf0.txt` `CMD_RC=0`（`adb` / `dart 3.13.3` / 磁盘均正常） | ❌ 排除 |
| 任务「空闲结束即停止」 | `RunOnlyIfIdle=False`（未启用空闲条件） | ❌ 排除 |
| 执行超时 | `ExecutionTimeLimit=PT2H`，实际只跑 8 分钟 | ❌ 排除 |
| 宿主资源耗尽 | 内存空闲 11.5GB / 磁盘空闲 64GB / 无 `Resource-Exhaustion-Detector` 新事件 | ❌ 排除 |
| **进程被一次性外部杀死** | 无残留进程、无法复现 | ✅ **判为一次性被杀** |

**加固（已落地，后续默认）**：

1. 作业脚本顶部 `exec 1>>_pt/<轮次>_progress.log 2>&1` —— **不再依赖中继 stdout 的缓冲语义**
   （`cmd.exe` 管道块缓冲 ⇒ 进程被杀时缓冲整段丢失，这正是「只有 570 字节」的成因）；
2. `trap '... SCRIPT_EXIT rc=$?' EXIT` —— 提前退出也留下带退出码与时间戳的最后一行；
3. 每个重步打印 `START/END` 时间戳，一眼看出卡在哪一步。

⇒ 加固后重跑一次即**贯通到底**（05:52–06:03，`SCRIPT_EXIT rc=0`）。纪律写入 `docs/17 §86.2` 与 `HANDOVER ★块`。
