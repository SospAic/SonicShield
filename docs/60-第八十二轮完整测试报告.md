## 二、本轮主题

### A. 设置页 tab 分组（FR-70，`docs/02 §1.9`）

- 需求来源：用户口头给出（此前文档**零登记**，本轮补登）。
- 实现：`lib/features/settings/settings_screen.dart` 的 `build()` 由单一 `ListView` 改为
  `DefaultTabController` + `TabBar`（**通用** / **语音与反击**）+ `IndexedStack`。
  `IndexedStack` **同时挂载两页**（非激活页 offstage），故既有 `find.text(...)` 渲染锁**无需改动**；
  仅语音/反击页的*交互*用例在点击前需 `switchTab` 到对应页。

### B. 首页常驻全局执行总开关（FR-71，`docs/02 §1.9`）

- 需求来源：用户口头给出「总开关放置到首页」（全局执行总开关本身已登记于 FR-39b，
  但**放置到首页**此前文档零登记，本轮补登）。
- 实现：`lib/features/dashboard/dashboard_screen.dart` 新增 `_RunMasterCard`，**与设置页同源**
  绑定 `PrefsKeys.runMasterMode`（三态 `auto/on/off`），状态行用纯函数 `RunPause` 如实显示
  当前是否处于暂停窗口 / 下次切换时刻。

### C. 总开关支持远程控制（FR-72，`docs/02 §1.9`）

- 控制端可远程切换端点总开关（命令 `run.master.set`，权限位 `script`，非法/缺失 `mode` 显式失败）。
- 控制台按 `rc.status` 的 `runMasterMode/paused` **回显**端点当前档与暂停态并**高亮当前档**。
- 新增 `lib/services/run_master_service.dart`（`ValueNotifier` 单一真源代理）⇒
  首页卡片 / 设置页 / 远程 `run.master.set` **三方同源**，**远程改动即时刷新端点本机 UI**
  （修「首页只在 `initState` 读一次、远程改了不刷新」的最后一公里）。

### D. 远程连接方案可选 + 节点下拉 + 一键测速（FR-73，`docs/02 §1.10`）

- 新增 `lib/remote/node_catalog.dart`：MQTT 节点目录（含**国内** `broker-cn.emqx.io`）+
  STUN 节点目录（小米 / B站 / 腾讯 / 芒果 + Google 回落）+ `RcTransport` 枚举
  （`tls` 8883 / `wss` 8084 / `quic` 14567）+ `NodeSpeedTest`（TCP/TLS 建连时延 + STUN 绑定请求 RTT）。
- 远程设置页新增「连接方案」「MQTT 节点」「STUN 节点」三个**下拉** + 「一键测速」
  （并发探测、可达优先、时延升序、最快打 ★）。
- `RemoteStore` 新增 `rc_transport` / `rc_mqtt_node` / `rc_stun_node`；
  `CallService.iceServers()` 支持固定单个 STUN（空串 = 自动全部并行，默认行为不变）。
- ⚠️ **QUIC 当前 Dart 客户端库不支持** ⇒ 选它**回落 TLS 并在 UI 明示**（不静默）。
- 文档：`docs/14 §10` 新增「连接方案与节点选择」。
