### 6.4 模拟器验证发现并修复的真实缺陷（P0/P1）

| ID | 级别 | 缺陷 | 修复 |
|---|---|---|---|
| BUG-007 | **P0** | 重装后通知渠道缺失：flutter_background_service 指定自定义 `notificationChannelId` 时**不自动创建 channel**（其源码 L89-95），`startForeground` 通知发布失败 → `CannotPostForegroundServiceNotificationException` 崩溃循环 | `main.dart` 启动即创建全部渠道（`createServiceChannel()`） |
| BUG-008 | **P0** | 后台服务引擎的 MethodChannel 无 handler：MainActivity 只给 UI 引擎注册，引擎隔离排布任务闹钟时 `MissingPluginException` 被静默吞掉 → **任务闹钟从未排布** | 新建本地插件 `packages/native_bridge`（path 插件），由 GeneratedPluginRegistrant 注册到所有引擎 |
| BUG-009 | **P1** | 主 FGS 声明 microphone 类型：服务被 RESPAWN 闹钟从后台复活时违反 while-in-use 语义 → SecurityException | 类型收窄为 `mediaPlayback\|dataSync`；新增 `MicGuardService`（microphone 类型）由用户前台交互启动，作为守卫的 while-in-use 通行证 |
| BUG-010 | P2 | Gradle wrapper 对镜像站 Java TLS 握手失败 | `distributionUrl` 指向本地 `file:///E:/dev/gradle-dist/gradle-9.3.1-all.zip`（其它机器可用腾讯镜像） |
