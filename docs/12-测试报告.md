### 6.2 构建排障实录（共 13 轮迭代，均真实发生）

| # | 故障 | 根因 | 解决 |
|---|---|---|---|
| 1 | Gradle wrapper 下载超时 | services.gradle.org 网络不可达 | distributionUrl 换腾讯镜像 + 手动放置发行包（`.ok` 标记） |
| 2 | Maven 依赖拉取失败（TLS handshake terminated） | dl.google.com/mavenCentral TLS 被网络干扰 | 全局 init script（`~/.gradle/init.d/mirror.gradle`）注入阿里云镜像 |
| 3 | init script 与 Gradle 9 PREFER_SETTINGS 冲突 | 向 project repositories 注入违反仓库模式 | 仅注入各项目 buildscript 仓库 |
| 4 | `NDK not configured`（28.2.13676358） | 全新 SDK 无 NDK | 手动下载 r28c 解压至 `ndk/28.2.13676358` |
| 5 | `platforms;android-34` 缺失 | audio_session 等老插件硬编码 34，且 platform-34 主包已停发 | init script 统一 `compileSdk=36`（向后兼容） |
| 6 | `record` 家族签名冲突（record_linux 0.7.2 vs interface 1.6.0） | 插件家族版本碎片，kernel 编译失败 | 升级 `record: ^7.1.1`（全家族配套版本），API 完全兼容 |
| 7 | workmanager 0.5.2 编译失败（v1 embedding 已移除） | 该包停止维护且本项目未实际使用 | 移除依赖（功能由引擎 Timer + 精确闹钟覆盖） |
| 8 | core library desugaring 未启用 | flutter_local_notifications 要求 | `isCoreLibraryDesugaringEnabled = true` + desugar_jdk_libs 2.1.4 |
| 9 | CMake '3.22.1' not found | 原生插件需要 CMake | 手动安装 CMake 3.22.1 + `abiFilters(arm64-v8a, x86_64)` |
| 10 | JVM target 不一致（Java 11 vs Kotlin 1.8） | 老插件混合配置触发 AGP 9 校验 | 根 build.gradle.kts 统一所有子项目 JVM 17 |
| 11 | `Cannot run afterEvaluate` | 注册时机晚于 :app 评估 | 移到 `evaluationDependsOn` 之前 |
| 12 | Kotlin 增量缓存损坏（Windows 文件锁） | 非正常退出残留 | 清理 build + `kotlin.incremental=false` |
| 13 | intl 与 flutter_localizations 约束冲突 | 模板要求 intl ^0.20.3 | 升级 intl 约束 |

> 以上适配已全部固化进仓库（gradle.properties / build.gradle.kts / init 脚本示例），
> 正常网络环境按 docs/10 操作可一次通过。
