# 08 · 合规与安全使用白皮书

> 本文档是产品的法律边界声明与合规设计说明。**它不是法律意见书**；
> 具体个案请咨询当地执业律师。

---

## 1. 产品的合法用途（Whitelist）

- 定时/随机提醒：久坐、喝水、服药、习惯养成；
- 助眠/专注音：随机间隔与随机音量的白噪音、舒缓提示；
- **噪声取证**：对持续性噪声骚扰进行本地录音留证与事件日志，
  用于后续沟通、物业/居委会调解、12345 投诉、报警或司法程序；
- 守护提示：独居家人的定时确认播报。

## 2. 明确禁止的用途（Redline）

1. **利用随机播放/随机音量/自动喊话功能骚扰、恐吓、报复任何他人**；
2. 在夜间（默认 22:00–07:00 免打扰时段）或任何时段制造干扰他人的噪声；
3. 录音取证用于侵犯他人隐私（如偷录私密场所对话）而非自我保护留证；
4. 任何违反使用者所在地法律法规的用途。

## 3. 主要法律风险提示（中国大陆为例）

| 行为 | 可能触碰的法律 |
|---|---|
| 随机时间大音量播放声音干扰邻居/他人正常生活 | 《治安管理处罚法》第 58 条（噪声干扰他人正常生活可处警告或罚款）；《噪声污染防治法》（社会生活噪声） |
| 夜间噪声扰民 | 同上，且从重情节 |
| 以喊话、恐吓音效威胁他人 | 《治安管理处罚法》第 42 条（写恐吓信或者以其他方法威胁他人人身安全）；情节严重可能涉刑 |
| 对他人正常生活造成持续干扰 | 《民法典》第 288 条起相邻关系条款（不动产相邻权利人应按有利生产、方便生活、团结互助、公平合理原则处理相邻关系）、第 1032 条起隐私权 |
| 在他人住宅/工作场所安装本应用设备进行干扰或窃录 | 可能构成非法侵入住宅、侵犯公民个人信息等 |

**正确姿势**：遭遇骚扰/噪声侵害时，优先选择**取证 → 沟通 → 投诉
（物业/12345/城管）→ 报警 → 诉讼**的合法路径；本应用的取证与日志功能
正是为此设计，而不是用于"以噪制噪"。

> 其他司法辖区（欧美、日韩等）对噪声滋扰（noise nuisance/disturbing the
> peace）、骚扰（harassment）同样有行政处罚或刑事责任，结论一致。

## 4. 应用内合规护栏（工程设计，不可绕过）

| 护栏 | 实现位置 | 说明 |
|---|---|---|
| 合规门 | `permission_flow.showComplianceGateOnce` | 首次启动强制阅读《合规使用须知》，不同意则引擎不可用（持久化标志） |
| 强制免打扰时段 | `ComplianceGuardrails.defaultQuietStart/EndHour` + `ScheduleEngine._applyQuiet` | 默认 22:00–07:00，UI 只能调窄（22–23 点开始 / 5–9 点结束）；物化期与执行期双重生效 |
| 最小冷却 | `ComplianceGuardrails.minCooldownSeconds = 60` | 编译期常量；物化去尾 + 执行期校验 |
| 音量上限 | `ComplianceGuardrails.maxMediaVolumePercent = 100` | 物化期裁剪 |
| 补执行限流 | `SchedulerConfig.catchUpLimit = 3`、逾期 10 分钟丢弃 | 防休眠唤醒后连响轰炸 |
| 全量审计 | exec_logs | 每次执行（含 skipped/failed）留痕，时间/来源/音量/时长可回溯 |
| 隐私默认 | 无 INTERNET 权限；麦克风数据不落盘 | 物理上无法外传 |

## 5. 应用商店政策

| 事项 | 结论 |
|---|---|
| `SCHEDULE_EXACT_ALARM` | 通用特殊权限，应用内引导用户授权；需在商店说明用途（"精确执行用户设定的提醒"） |
| `USE_EXACT_ALARM` | Play 政策仅限闹钟/日历核心功能应用；**本应用不使用**，避免审核风险 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Play 政策要求"用户显式操作 + 核心功能必要"；应用内为按钮主动申请（引导页），并说明后果 |
| 后台麦克风（iOS） | 用途字符串具体化；守卫模式提供明确的用户开关 |
| "骚扰反击"类描述 | **上架文案严禁出现"反击/报复/整蛊他人"等表述**；统一使用"提醒/取证/守护"话术 |

## 6. 数据与隐私合规

- 处理原则：最小必要（麦克风音频仅瞬时计算能量）、目的限定
  （本地检测与取证）、存储限定（应用私有目录）；
- 对照《个人信息保护法》：麦克风属敏感个人信息，应用通过
  运行时权限 + 首启告知 + 状态栏系统提示满足告知同意要求；
- 取证文件含他人声音的，使用者应仅将其用于合法维权目的并妥善保管，
  不得公开传播（可能侵犯他人肖像/声音权益或构成侮辱诽谤）；
- v1 无网络能力，天然满足"本地化存储"。
