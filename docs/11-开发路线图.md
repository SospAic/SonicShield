# 11 · 开发路线图

> v1.0（本次交付）→ v2.0（增强）→ v3.0（平台深化）

---

## v1.0 —— MVP（✅ 已交付）

- [x] 六种触发（固定/每日/每周/随机窗口/随机间隔/声音）
- [x] 六种动作（播放/TTS/通知/取证录音/震动/组合）
- [x] 随机化五维（时刻/日期/时长/音量/音源权重）+ 确定性种子
- [x] Android 双通道后台（前台服务 + 精确闹钟）+ 开机恢复
- [x] 电源三档策略 + 低电量降级 + 厂商保活引导（8 厂商深链）
- [x] 声音守卫 v1（能量阈值 VAD）+ 取证录音
- [x] 合规护栏全家桶（合规门/免打扰/冷却/审计日志）
- [x] 六页 UI（Material 3 / 动态色 / 深色模式 / 中文本地化）
- [x] 单测 41 例全绿 + analyze 清零 + CI + 模拟器脚本 + 全套文档

## v1.1 —— 体验补强（2–4 周）

- [ ] 守卫页实时电平表（引擎 → UI 电平流直显）
- [ ] 日志筛选/导出 CSV、取证文件管理与分享
- [ ] 任务模板与复制；批量启停
- [ ] 动态刷新计划：下次触发卡片支持"跳过这一次"
- [ ] 音源剪辑预览（起止点标记）
- [ ] 双语（en）完善与无障碍走查（TalkBack/VoiceOver）

## v2.0 —— 智能增强（1–2 月）

- [ ] **YAMNet TFLite 声音分类**（521 类白名单触发，docs/06 §6）
- [ ] 统计看板：触发热力图、事件时间分布、电量影响报告
- [ ] 加密备份（用户口令 AES-GCM）与手动导入导出
- [ ] Drift 类型安全数据层迁移（ADR-003 落地）
- [ ] 时区/DST 严格语义（timezone 库，海外用户）
- [ ] 桌面端（Windows/macOS）只读看板 + 蓝牙/局域网设备触发（评估）

## v3.0 —— 平台深化（评估）

- [ ] Android 全原生保活引擎（FlutterEngineGroup 托管，进一步抗杀）
- [ ] Wear OS 快捷开关；iOS 小组件与 App Intents（Siri 场景）
- [ ] 多设备协同（自建端到端加密同步，默认关闭、显式开启）
- [ ] 插件化动作系统（webhook/HTTP 触发器等，含合规评审门）

## 长期原则

1. 每个版本发布前重跑 docs/09 全量门禁；
2. 合规护栏（免打扰/冷却/审计）在任何迭代中**只增强不削弱**；
3. 隐私红线（本地处理/不上传）不做妥协，网络能力引入需独立评审。
