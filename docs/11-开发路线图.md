# 11 · 开发路线图

> v1.0.x（本次交付）→ v1.1（体验增强）→ v2.0（智能）→ v3.0（平台深化）
> 对标产品：Tasker / MacroDroid（自动化）、Alarmy（任务闹钟）、
> Tide 潮汐 & Bose Sleep（助眠声景）、Sleep Cycle（渐强唤醒）、IFTTT（触发联动）。

- [x] 六种触发（固定/每日/每周/随机窗口/随机间隔/声音）+ 六种动作

- [x] 电源三档 + 低电量降级 + 8 厂商保活引导
- [x] 合规护栏全家桶（合规门/免打扰/冷却/审计）+ **60 条预置音效库**
- [x] 模拟器端到端验证 + 杀进程自愈实测（5s）+ AOT Release 构建通过
- [x] 文档 docs/00-12 + HANDOVER 交接文档 + CI

## v1.1 —— 体验增强（2–4 周，本轮规划）

### A. 声景引擎（对标 Tide/Bose Sleep）

- [ ] **多轨混音**：雨声+雷声+风声多轨叠加，独立音量/循环/淡入淡出
      （实现：just_audio 多实例 + 音量包络，预置库 60 条为素材）
- [ ] **渐强唤醒**：触发后音量 0→目标值线性爬升 N 分钟（Sleep Cycle 式，
      对应 PlayAudioAction 增加 `rampUpSec`）
- [ ] 预置库 v2：真实 CC0 采样扩展包（来源建议：freesound.org CC0、
      BBC Sound Effects 档案；按现行 manifest 格式打包，保持免版权红线）
- [ ] 音效循环播放模式（短音效 loop 到随机时长）

### B. 自动化体验（对标 Tasker/MacroDroid）

- [ ] 任务模板库与一键复制；批量启停
- [ ] 「跳过下一次」按钮（occurrence 单条 skip）
- [ ] 触发前置条件：仅充电/仅 Wi-Fi/仅耳机断开（现有 onlyWhileCharging 扩展）
- [ ] 日志筛选/搜索 + CSV 导出（share_plus 已就位）

### C. 可信与合规

- [ ] 审计日志的"合规章"摘要视图（本周执行/免打扰遵守率/冷却命中率）
- [ ] 免打扰时段日历可视化
- [ ] 权限体检页升级（精确闹钟/电池白名单/麦克风 FGS 状态一键检测）

### D. 工程质量

- [ ] flutter drive 集成测试进 CI（wrapper 已本地化，KVM runner 即插即用）
- [ ] Patrol UI 测试补关键路径（新建任务→保存→列表）
- [ ] 性能基线：内存/电量采样脚本化（dumpsys 采集入报告）

## v2.0 —— 智能增强（1–2 月）

- [ ] **YAMNet TFLite 声音分类**（521 类白名单触发，docs/06 §6 设计已就绪）
- [ ] 统计看板：触发热力图、事件分布、电量影响
- [ ] 加密备份（用户口令 AES-GCM）与导入导出
- [ ] Drift 类型安全数据层迁移（ADR-003）
- [ ] 时区/DST 严格语义（timezone 库）
- [ ] 多语言（en 全量）

## v3.0 —— 平台深化（评估）

- [ ] Android 全原生保活引擎（FlutterEngineGroup 托管）
- [ ] Wear OS 快捷开关；iOS 小组件与 App Intents
- [ ] 多设备端到端加密协同（默认关闭）
- [ ] 插件化动作系统（webhook，含合规评审门）

## 长期原则

1. 每次发布重跑 docs/09 全量门禁（单测/analyze/集成/保活专项）；
2. 合规护栏（免打扰/冷却/审计）只增强不削弱；
3. 隐私红线（本地处理/不上传）不做妥协；
4. 音效素材零版权（合成或 CC0，入库前审查来源协议）。
