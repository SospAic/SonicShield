## 1. 环境搭建

### 1.1 组件与版本

| 组件 | 版本 | 说明 |
|---|---|---|
| Flutter SDK | 3.24+（开发基准 3.47.3 stable） | https://docs.flutter.dev 或国内镜像 |
| JDK | 21（Temurin） | AGP 9.x 要求 17+ |
| Android SDK | Platform 36 / Build-Tools 36.0.0 / Platform-Tools | |
| Gradle | 9.3.1（wrapper 自动） | |
| Android Studio | 可选（仅模拟器与 SDK 管理） | |

### 1.2 环境变量（Windows 示例）

```powershell
setx JAVA_HOME "E:\dev\jdk\jdk-21.0.2"
setx ANDROID_HOME "E:\dev\android-sdk"
# PATH 追加：flutter\bin、platform-tools
# 国内加速（可选）
setx PUB_HOSTED_URL "https://pub.flutter-io.cn"
setx FLUTTER_STORAGE_BASE_URL "https://storage.flutter-io.cn"
```

### 1.3 国内镜像加速（本仓库已内置）

- `android/gradle/wrapper/gradle-wrapper.properties`：Gradle 发行包走
  腾讯镜像（`mirrors.cloud.tencent.com/gradle`）；
- `android/settings.gradle.kts` / `android/build.gradle.kts`：Maven 仓库
  优先阿里云（google/public/gradle-plugin），官方源兜底。
  海外 CI 构建可整体还原为官方源（不影响功能）。

### 1.4 验证

```bash
flutter doctor        # Android toolchain 应为 [√]

adb devices
```

## 3. 构建

```bash
flutter build apk --debug              # 调试包（本次交付已验证）
flutter build apk --release            # 发布包（需签名配置）
flutter build appbundle --release      # Play 上架格式
flutter build ipa --release            # iOS（需 macOS + Xcode）
# 分 ABI 瘦身
flutter build apk --release --split-per-abi
```

## 4. 签名

1. 生成密钥：
   `keytool -genkey -v -keystore E:\keys\sonicshield.jks -keyalg RSA -keysize 2048 -validity 10000 -alias sonicshield`
2. `android/key.properties`（**不入库**，已在 .gitignore）：
   ```properties
   storePassword=*** / keyPassword=*** / keyAlias=sonicshield
   storeFile=E:\\keys\\sonicshield.jks
   ```
3. `android/app/build.gradle.kts` 增加 signingConfigs.release 并引用；
4. CI 签名：密钥以 base64 存 GitHub Secrets，构建前还原。

## 5. CI（已交付 .github/workflows/ci.yml）

三段流水线：
1. **analyze-test**：pub get → analyze(--fatal-infos) → test --coverage；
2. **android-build**：release APK 产物上传 artifact；
3. **emulator-test**：KVM 模拟器装包 + 授权 + 集成冒烟。

## 7. FAQ

| 问题 | 处理 |
|---|---|
| Gradle wrapper 下载失败 | 使用 §1.3 镜像配置；或手动下载发行包放入 `%USERPROFILE%\.gradle\wrapper\dists\<hash>\` 并创建 `.ok` 标记 |
| `NDK not configured` | 本项目默认无需 NDK（已注释 ndkVersion）；若启用了带原生代码的插件，用 sdkmanager 安装首选版本 |
| `flutter_background_service` 版本差异 | `foregroundServiceTypes` 枚举名随版本变化，参照插件 CHANGELOG 调整 `background_service_manager.dart` |
| Android 15 开机不自启 | 平台对 BOOT_COMPLETED FGS 类型有限制：完成保活引导 + 下次闹钟自愈兜底 |
| 模拟器无声音 | 用带 Google APIs 的镜像或真机验证音频链路 |
| 杀进程后不恢复 | 检查精确闹钟权限（12+）与电池白名单；`adb shell dumpsys alarm \| grep sonicshield` 查看排布 |
