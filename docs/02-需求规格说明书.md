# 02 · 需求规格说明书

> 依据 GB/T 8567 与 IEEE 830 风格组织；编号规则：FR-x 功能需求，NFR-x 非功能需求。
> 每条需求标注优先级（P0 必须 / P1 应该 / P2 可选）与验收标准。

---

## 1. 功能需求

### 1.1 任务管理

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-01 | 创建/编辑/删除/启停任务 | P0 | 删除任务级联清理其计划与日志入口；启停即时生效并触发重算 |

### 1.8 执行条件（条件层，对应 `TaskCondition`）

任务可配置**前置条件**：全部满足才执行，任一不满足则计划标 `skipped` 并写审计。
条件层借鉴行业领先自动化工具（Tasker / MacroDroid 的条件段与约束）。

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-64 | 仅充电时执行 | P2 | 充电/满电视为满足；无电池平台视为满足 |
| FR-65 | 最低电量阈值（0–100，可选） | P2 | 低于阈值跳过，审计含具体数值 |
| FR-66 | 每日时段窗口（含跨零点） | P1 | 窗口外跳过；跨零点（如 22:00–07:00）判定正确 |
| FR-67 | 仅 Wi-Fi 下执行（可选） | P2 | 移动网络下跳过；**不新增运行时权限**（仅 normal 级 `ACCESS_NETWORK_STATE`） |
| FR-68 | **通话中不执行（默认开启）** | P0 | 通话中跳过并写审计；判定**不得申请 `READ_PHONE_STATE`**；对未配置条件的历史任务同样生效 |
| FR-69 | 条件无法判定时按"满足"处理（不静默停掉自动化） | P1 | 桥不可用（如 iOS）时自动化不被整体阻断 |

### 1.10 远程连接（节点与连接方案）

| 编号 | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-73 | **远程连接方案可选 + 节点下拉 + 一键测速**：远程设置页提供「连接方案（TLS 8883 / WSS 8084 / QUIC 14567）」「MQTT 节点」「STUN 节点」三个下拉切换，并提供「一键测速」并发探测各候选节点的建连时延、按可达优先/时延升序排序（最快打 ★）；MQTT 节点目录含**国内** `broker-cn.emqx.io`，STUN 节点目录含国内多家（小米/哔哩哔哩/腾讯/芒果等）与 Google 回落 | P2 | ① 三个下拉均可切换并写回 `rc_transport` / `rc_mqtt_node` / `rc_stun_node`；② 一键测速并发探测并排序展示（TCP/TLS 建连 + STUN 绑定请求 RTT）；③ 三种方案均 `secure = true`，QUIC 因 Dart 客户端库不支持**回落 TLS 并在 UI 明示**（不静默）；见 `lib/remote/node_catalog.dart`、`lib/features/remote/remote_screen.dart`、第八十四轮登记 |
| FR-74 | **首页「全局执行开关与后台保活开关真实生效」**（用户明文指令）：守护首页的两个开关 —— 「全局执行开关（节假日自动暂停）」与「后台保活开关」—— 拨动后必须**真实生效**（不只是改一个存储值）：① 全局执行开关写回 `PrefsKeys.runMasterMode` 并经 `RunMasterService` 广播，端点调度**立即**按新档位裁定（`off` ⇒ 不执行任何任务；`on` ⇒ 忽略节假日暂停；`auto` ⇒ 按暂停窗口）；② 后台保活开关写回后**实际**启停后台引擎/前台服务（`BackgroundServiceManager`），关掉后引擎不再 tick、不再触发调度与反击 | P0 | ① 首页拨 `off` → 端点在暂停窗口内/外**均不执行**任务（有可断言的行为差异，不是只改 prefs）；② 拨 `on` → 暂停窗口内仍执行；③ 拨 `auto` → 恢复按窗口裁定；④ 保活关 → 引擎停（`isForeground=false`，tick 计数停止增长）；保活开 → 引擎起（恢复 tick）；⑤ 两个开关的**写入值**与**实际行为**逐档一一对应（防「只写不生效」的静默失败）；见 `lib/features/guard/guard_screen.dart`、`lib/services/run_master_service.dart`、`lib/services/background_service_manager.dart`、第八十四轮登记 |

## 3. 约束

1. **平台约束**：iOS 无系统级常驻方案，被杀后仅通知兜底（用户预期管理）。
2. **政策约束**：`USE_EXACT_ALARM` 仅闹钟/日历类应用可在 Play 上架使用；
   本应用默认走 `SCHEDULE_EXACT_ALARM` 用户授权流（见 docs/08 §5）。
3. **合规约束**：免打扰护栏、冷却下限、音量上限为硬编码，配置不可绕过。
4. **网络**：v1 不申请 INTERNET 权限（最大化隐私）；
   v2 云备份功能将作为显式可选模块评审后加入。

## 4. 范围外（Out of Scope）

- 云端同步/多设备管理（v2+）
- 他人声纹识别、定向追踪（**永久 Out of Scope，违反产品红线**）
- 电话/短信类自动化动作
- iOS 小组件 / Watch 扩展（v2 评估）
