## 二、四簇功能落地（A / B / C / D）

### 2.1 A · 招人烦音效库（`annoy` 分类）

- `tool/gen_sfx.dart` 新增 `annoy` 分类（咳嗽 / 吐痰 / 嘲笑 / 「干啥呢」等 10 条），重生成
  `assets/audio/presets/annoy_*.wav` 并刷新 `assets/audio/presets_manifest.json`。
- 本机（任务编辑器 / 指令组）与远程（`sound.play` 按 `preset` / `assetId` / `category` 优先级解析）
  均按 `tags` 命中；`CounterPlanService.resolvePresetAudioIds` 负责计划↔音源桥接。

### 2.2 B · 仿真 TTS（离线 + 在线音色）

- 新增 `lib/domain/models/tts_voice.dart`：普通话 + **东北话**、**男女齐全**的在线音色目录。
- 新增 `lib/services/tts_service.dart`（`say(text, voiceId:, volume:)`）与
  `lib/services/online_tts_client.dart`；离线走系统 TTS，在线走可配置接口。
- `TtsAction.voiceId` 全链路接线：任务编辑器 / 指令组编辑器 / 反击计划 / 远程
  `tts {text,volume,voiceId?}`。

### 2.3 C · JSON 随机反击计划

- 固定 schema **`sonicshield.counterPlan/1`**：`lib/domain/models/counter_plan.dart`
  （`validate` / `fromJson` / `toJson` / `tryParse`）。
- 中国法定休息日/工作日基准：`lib/domain/scheduling/china_holidays.dart`。
- 物化与随机：`counter_plan_materializer.dart` / `counter_plan_random.dart`；
  服务层 `lib/services/counter_plan_service.dart`；AI 通道 `lib/services/deepseek_service.dart`。
- **区间（与需求逐位一致）**：
  - 工作日：白天音量 **50–80%**、夜间 **30–50%**；
  - 休息日：白天 **50–80%（可选）**、夜间 **10–30%（可选）**；
  - 动作持续：白天 **3–8s**、夜间 **3–5s**。
- **三条通道**：① DeepSeek 一键生成（`response_format=json_object` + 允许集收敛 ⇒ **100% 回导**）、
  ② 本机按同区间随机生成、③ 远程 `plan.apply / plan.get / plan.stop`。
- **API 地址与 Key 配置模块**：`lib/data/repositories/api_config_store.dart`；
  远程 `planGet` 只读免授权，`planApply` / `planStop` 需 `script` 位，未登记命令 `denyAll`。
- **JSON 模版下载**：支持导出模版到本机并分发（`file_picker` / 分享链路）。

### 2.4 D · 实时随机动态反击

- `lib/services/reactive_counter_service.dart`：轻/重声音**分级**（轻量不理、重量随机反击）、
  静默 **15–25 分钟**后渐进反制、执行期 `_acting` **防叠加**、异常**如实 `failed`**。
- 接线 `lib/services/background_engine.dart`；**与手动发送互斥**，不与手动内容冲突或崩溃。

### 2.5 DeepSeek 内置默认 Key（非写死）

```dart
static const String _builtInApiKey = String.fromEnvironment(
  'DEEPSEEK_API_KEY',
  defaultValue: 'sk-…（出厂默认）',
);
static String get defaultApiKey => _builtInApiKey;
```

- **三级覆盖**：① 编译期 `--dart-define=DEEPSEEK_API_KEY=...`；② 设置页运行期改写
  （"语音与接口 → DeepSeek 接口配置"）；③ 未配置回内置默认。
- **语义区分**："从未配置"（回默认）≠ "显式清空"（停用 API）；`clearAll` 回内置默认；
  由 **`AC-08`** 锁住「默认 ≠ 写死」。
- ⚠️ **安全提示**：默认 Key 存在于构建产物与 git 历史，生产建议用 `--dart-define` 注入专属 Key。
