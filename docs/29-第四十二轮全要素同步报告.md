## 四、发现并修正的 13 处漂移（逐条留痕）

### 4.1 一类**系统性口径错误**（5 处，最值得记的一条）

**表述**：`可测面仍有 N 行未覆盖（其中 490 行是设备层豁免…）`

**为什么是错的**：设备层豁免 490 行**已按定义剔出可测面分母**
（`可测面 LF 9584 = 全局 LF 10074 − 490`）⇒ 它**不可能同时**出现在可测面的 N 行残缺口里。
这句话会让读者以为"1138 里只有约 648 行是真缺口"，**把缺口缩水 43%**。

| 位置 | 原文 N | 处置 |
|---|---|---|
| `docs/12 §75.7` | 1138 | 改为「其中约 4 行结构性不可达…；**490 行豁免不在可测面分母内**（其中 488 行未覆盖）⇒ **全局合计 1626 行**」+ 加更正说明 |
| `docs/17 §69.3` | 1485 | 同型更正 |
| `docs/17 §70.5` | 1370 | 同型更正 |
| `docs/17 §71.6` | 1261 | 同型更正 |
| `docs/17 §72.6` | 1138 | 同型更正 + 全局合计 1626 |

> 算术核对：`全局未覆盖 1626 − 可测面未覆盖 1138 = 488 = 490 − 2`（豁免里已覆盖 2 行）✅
