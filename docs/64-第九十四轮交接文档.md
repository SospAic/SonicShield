### 1.2 PA-05 墙钟偶发：根因定死 + 根除（本轮唯一一处「判据变严」）

`test/playback_service_justaudio_test.dart` 的 PA-05 是仓库里**最老的偶发红**（2026-10-04 起四次复现）。
历史上三次「修」都在**加大等待**（5s → 20s → 120s），全都治标 —— 因为根因不是「等得不够久」：

- 播放窗口 `maxDurationMs: 400` = **8 个** `Future.delayed`；
- 渐强 `rampUpMs: 200` = **40 个** 5ms tick；
- `_rampUp` 是 **unawaited**，而 `play()` 的 `finally` 会 `player.dispose()`。

⇒ **窗口一结束就把渐强掐死**，且掐死在第几步取决于负载。
历史实测末值 **0.363 / 0.705 / 0.743 / 0.781**，分别对应第 **17 / 35 / 37 / 39** 步。
`_waitUntil` 等 120s 也没用 —— 它等的是**永远不会再跑的定时器**。

**修法**：`maxDurationMs: 0` ⇒ 窗口回落为**文件时长 2000ms**（40×50ms tick），
渐强仍 200ms（40×5ms）⇒ **同为 40 个定时器、标称时长 10:1**。
任何负载模型（均匀变慢 / 固定额外开销 / 定时器被饿死 ≈100×）下渐强都**必定先跑完**。

**同时收紧判据**：步数断言由 `volumes.length > 10` 改为 **`>= 41`**（1 激活期 + 40 渐强步）。
这是本轮唯一一处**判据变严**的改动 —— 既根除偶发，又把「只跑了一半」也锁死。

**同类第二处（RS-ND4，本轮门禁实测复现一次）**：`test/remote_screen_test.dart` 的
「一键测速」是**真实网络 IO**（4 个 MQTT + 7 个 STUN 并发探测），探测期间界面有持续动画
⇒ 原来的 `pumpAndSettle()` 会等满 10s 抛 `pumpAndSettle timed out`，**失败原因伪装成业务缺陷**。
改为「渲染出结果就停」的有界轮询（200×100ms，含 `runAsync`），断言一字未改。
单文件复跑 **32/32 通过（21 秒）**。
⇒ **可复用判据：`pumpAndSettle` 遇到「不会自己停」的东西（unawaited 渐强 / 持续动画 / 真实网络 IO），
必须换有界轮询。**

### 1.4 阈值为什么不抬

实测 99.61% 已高于 `COVERAGE_MIN=98.6`，按 ratchet 规则本可抬到 **99.0**。**本轮不抬**，理由：

1. 残差已粉末化（64 行分散在 20 个文件、16 个文件各只剩 1 行）⇒ 抬到 99.0 相当于要求
   `MIN_COVERED ≥ 14969`，只留 **87 行**抖动余量，而 1 行覆盖波动就会判红；
2. 该项目的 ratchet 语义是「**只许涨不许跌**」，抬上去就再也降不下来 —— 在残差粉末化阶段抬，
   会把下一轮变成「为 1 行返工」的循环；
3. **留待残差 <30 行时一次性抬**（已写进 `docs/12 §128.4` 与 `docs/17 §125`）。

## 6. 本轮踩到 / 复用的教训（可直接搬）

- 🔴 **「偶发红」先问「被测的东西还在不在跑」**，再问「等得够不够久」。PA-05 三次加时都失败，
  是因为 `dispose()` 之后定时器**永不再跑**；加时等于等一个不会发生的事件。
- 🔴 **窗口:事件的「定时器个数比」才是并发稳定性的真变量**，不是标称毫秒比。
  400ms/8 tick : 200ms/40 tick 标称 2:1，但事件数 1:5 ⇒ 负载一拉长，事件多的一方必输。
- 🔴 **判断「长尾能不能补」要看分布形状，不看绝对行数**：131 行集中在 1 个文件 = 还能补；
  64 行分散在 20 个文件 = 该换打法（按文件补完）。
- 🔴 **不要用「登记豁免」解决覆盖率残差** —— 那是改尺子。豁免只适用于**结构不可达**
  （平台通道把异常折叠成 `null`、`switch` 穷尽分支等），且必须**逐段举证**。
- 🔴 **写文档前先读锁**：`test/doc_gate_consistency_test.dart` 的 `BAS`/`BRL`/`MCL`/`CCL`/`RCL`/`SSL`
  六族锁会咬住「数字不一致 / 自述过期 / 标题轮次过期 / 接力棒指针过期」。
  本轮开工时**先把 6 个落点的旧数字 grep 出来**再改，避免了「改了 A 忘了 B」。
- 🔴 **`####` 标题不得以某个 `###` 标题全文开头**（子串中毒会让 11 处文档锁定位错段）。
  `CHANGELOG.md` 里现存 52 处历史碰撞（全在 3202–4017 行的旧版本段），**当前区干净，勿再新增**。
