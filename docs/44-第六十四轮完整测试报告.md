### 4.2 本轮最贵的坑（RS-14 真实红修）

`ScaffoldMessenger` 的 `SnackBar` 是**队列**语义 —— 看门狗提示的**消失计时器**要**入场动画之后**才启动，
所以 `await tester.pump(const Duration(seconds: 8)); await tester.pump();` **一次跳不到它**（首跑与第一次修法都因此判红）。
稳定修法 = **有界轮询**：

```dart
var found = false;
for (var i = 0; i < 40 && !found; i++) {
  await tester.pump(const Duration(milliseconds: 300));
  found = find.textContaining('8 秒未收到端点回应').evaluate().isNotEmpty;
}
expect(found, isTrue, reason: '端点若从未回应（未确认也未开始执行），必须由本端主动说明');
```
