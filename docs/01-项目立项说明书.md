# 01 · 项目立项说明书

> 项目名称：声盾 SonicShield
> 版本：v1.0 ｜ 状态：MVP 已实现 ｜ 文档责任人：项目组

---

## 1. 项目背景

日常生活中存在大量「需要按计划或按情境自动发出声音/提示」的合法需求：

- **定时与提醒**：久坐提醒、喝水提醒、按时服药提示音；
- **助眠/专注**：随机白噪音、随机间隔的舒缓提示；
- **习惯养成**：随机时间的工作提示音，避免形成" predictable 打卡"；
- **自我保护与取证**：遭遇持续性噪声骚扰（邻里噪声、职场滋扰等）时，
  对噪声事件进行**自动检测、提示与录音留证**，为后续沟通、投诉、
  调解或司法程序保留完整证据链；
- **守护场景**：独居老人/儿童的定时确认提示。

用户的核心痛点是：现有工具要么只能固定定时（无随机化能力），要么无法在
后台长期可靠运行，要么缺乏「检测到声音 → 自动做出响应」的联动能力。

## 2. 项目定位（边界即红线）

声盾 SonicShield 定位为 **个人音频自动化与自我保护工具**。

**只做：**

- 时间维度随机化（时间/日期/时长/音量）的音频播放与动作执行；
- 基于设备麦克风的**本地**声音事件检测与响应；
- 本地录音取证与完整执行日志。

**不做 / 明令禁止：**

- ❌ 不提供任何「针对特定他人」的定向能力（不识别他人设备、不做定向投送）；
- ❌ 禁止将随机播放/喊话功能用于骚扰、恐吓、报复他人；
- ❌ 不上传任何音频数据，不做云端声纹识别；
- ❌ 默认开启强制免打扰时段（22:00–07:00），防止夜间扰民。

> 详细法律分析见 [08-合规与安全使用白皮书](08-合规与安全使用白皮书.md)。

## 3. 目标用户画像

| 画像 | 核心诉求 | 主要功能 |
|---|---|---|
| 噪声困扰者 | 留证、自我提示、合法应对 | 录音取证、声音守卫、日志导出 |
| 效率/习惯用户 | 随机化的提醒节奏 | 随机窗口、随机时长/音量播放提示音 |
| 助眠/白噪音用户 | 不规律的舒缓音效 | 随机间隔 + 随机音量的低音量播放 |
| 家庭守护者 | 定时确认提示 | 每日/每周定时播报 |

## 4. 产品目标与成功指标

**版本目标（v1.0）**

1. 六种触发方式全量可用，随机参数完备（时刻/日期/时长/音量/音源加权）；
2. Android 后台 7×24 可靠执行：进程被杀、Doze、重启三场景自恢复；
3. iOS 在平台限制内最大化：前台/后台音频执行 + 被杀后本地通知兜底；
4. 电源管理三档策略 + 低电量自动降级；
5. 声音守卫本地检测可用，取证录音落盘。

**成功指标（发布后 3 个月）**

- 任务执行成功率 ≥ 99%（24h 观察窗内）；
- 后台存活率 ≥ 95%（主流厂商设备，完成保活引导后）；
- 崩溃率 < 0.1%；
- 应用商店「合规与隐私」评分无差评集中投诉。
