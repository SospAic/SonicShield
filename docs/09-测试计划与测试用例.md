## 4. 保活专项（adb 脚本化，scripts/emulator_test.ps1|sh）

| ID | 场景 | 操作 | 通过标准 |
|---|---|---|---|
| ST-01 | 进程被杀 | `adb shell am kill <pkg>` | 下一发精确闹钟重新拉起服务；到期任务执行 |
| ST-02 | Doze 逐级 | `dumpsys deviceidle step` 至 idle | AllowWhileIdle 闹钟按时触发 |
| ST-03 | 强制深睡 | `force-idle` 30 分钟（含计划任务） | 恢复后 catchUpLimit=3、过期 10min 丢弃 |
| ST-04 | 开机恢复 | `adb reboot`（should_run=true） | BootReceiver 拉起服务 |
| ST-05 | 升级恢复 | `adb install -r` 同签名 APK | MY_PACKAGE_REPLACED 拉起服务 |
| ST-06 | 守卫触发 | 对麦克风播放 > 阈值声音 | 事件 → 动作执行 → 日志 source=sound |
