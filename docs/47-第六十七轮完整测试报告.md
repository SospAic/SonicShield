## 五、🔴 本轮最贵的两个坑（单例状态跨用例污染）

1. 🔴 **`start()` 开头 `if (_running) return;`** —— `_running` 是单例字段。第 2 例起 `start()`
   直接 return ⇒ `debugClientFactory` 永不被调用 ⇒ 传输层全在 `client == null` 早退 ⇒
   症状是**「订阅集合恒为空」**（3 例集体假红，与被测点毫无关系）。
   **解法：`tearDown` 必须 `await svc.stop()`**。
2. 🔴 **`svc.start()` 把 `audit` 写成捕获当轮 `db` 的闭包**，而 `RcAssistHost` 是单例 ⇒
   下一例握手往**已关闭的库**写审计 ⇒ `DatabaseException(error database_closed)`。
   **解法：`tearDown` 必须 `audit = null; onCommand = null`**。
3. ⚠️ **`grant()` 在 `phase != active` 时静默返回 `false`** ⇒ 权限一位没开。
   **解法：走完 `assist.hello` 握手，并断言 `grant()` 返回 `true`**（把静默失败变显式红）。
4. ⚠️ **测量跑期间工作树必须冻结**：本轮在权威测量跑**运行中**创建了新测试文件 ⇒
   功能层把它当半成品加载（3 个编译错）⇒ **FAIL**。
