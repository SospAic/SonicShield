# 06 · 声音检测与自动响应设计

> 对应实现：`lib/services/sound_guard_service.dart` + 引擎内 `onSoundEvent()`

---

## 1. 设计目标

在设备本地实时检测"用户关心的声音事件"（噪声、喊声、敲击等），
以**低功耗、零上传、可解释**的方式驱动声音触发类任务执行
（播放提示、录音取证、通知等）。

## 2. 检测管线（v1：能量阈值 VAD）

```
麦克风（16kHz · 单声道 · PCM16，record 流式）
   │  ~每 40ms 一个 chunk
   ▼
RMS 计算（每 8 字节抽 1 样本，CPU 减半）
   │  dBFS = 20·log10(rms / 32768)
   ▼
电平流 levels（供 UI 电平表 / 调参）
   │
   ▼
状态机：是否 ≥ 阈值 thresholdDb？
   ├─ 是：累计 loudSince；持续 ≥ minDurationMs 且已过 cooldownSec
   │      → 产生 SoundEvent(detectedAt, peakDb, durationMs)
   └─ 否：复位累计器
   │
   ▼
引擎 onSoundEvent()：
   遍历启用的 soundTriggered 任务
   → 任务级冷却二次校验（防多任务串扰）
   → runAction() 执行动作
   → 写 occurrences（id=taskId@sound@ts, status=done）+ exec_logs
```

### 2.1 参数（守卫页可调，持久化于 sound_profiles 表）

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| thresholdDb | -35 dBFS | [-70, -10] | 越大越不敏感；-35 约对应"正常说话在 3m 外" |
| minDurationMs | 800ms | 200–3000 | 过滤关门、咳嗽等瞬时噪声 |
| cooldownSec | 120s | 30–1800 | 事件级冷却，防连环执行 |
| onlyWhileCharging | off | — | 省电场景（FR-53） |

### 2.2 事件流协议（引擎 → 未来 UI 电平表）

```dart
Stream<double>  levels   // 实时 dBFS，UI 渲染柱状电平表
Stream<SoundEvent> events // 触发事件
```

v1 电平表在守卫页显示引擎广播状态；实时波形直显为 v1.1 增强
（通过 flutter_background_service 的消息桥转发电平采样）。

## 3. 与调度引擎的关系

- 声音触发任务**不进时间计划**（`ScheduleEngine.materialize` 对
  SoundTrigger 返回空），完全由守卫服务驱动；
- 任务级冷却取 `max(守卫全局冷却, 任务 cooldownSec)` 双重校验；
- 每次触发写入 occurrences（source=sound），保证日志与"下次触发"语义一致。

## 4. 功耗与性能

| 项 | 数据/手段 |
|---|---|
| 采样 | 16kHz mono PCM16 ≈ 32KB/s 内存流，不落盘 |
| CPU | 每 chunk 仅一次 O(n/8) RMS；实测 < 1% 单核 |
| 驻留 | 随前台服务 microphone 类型常驻；仅充电选项 / saver 模式自动暂停 |
| 唤醒 | 不额外持有唤醒锁；chunk 到达由 AudioRecord 驱动 |

## 5. 隐私红线（与 docs/08 联动）

1. **原始音频不存储**：PCM 仅在内存中计算能量即丢弃；
2. **不上传**：v1 无网络权限，物理上不可能外传；
3. **录音取证是显式动作**：仅当任务配置 recordEvidence 且事件触发时，
   才开始写盘，且文件带 `.evidence.m4a` 标记存于应用私有目录；
4. **系统可见性**：后台使用麦克风时系统状态栏显示麦克风图标；
5. **用户可控**：守卫总开关一键关闭，参数页可随时收紧灵敏度。

## 6. v2 路线：声音事件分类（YAMNet / TFLite）

| 项 | 方案 |
|---|---|
| 模型 | TF-Lite int8 YAMNet（~4MB，521 类 AudioSet 标签） |
| 管线 | v1 VAD 触发 → 窗口缓冲（0.96s × 3）→ 分类 → 类别置信度过滤 |
| 目标类别 | 说话/喊叫/音乐/敲击/犬吠等白名单子集 |
| 接口演进 | `SoundEvent` 增加 `List<(label, score)>`；任务配置增加 `targetClasses` |
| 隐私 | 模型本地推理，与 v1 同红线 |
| 降级 | 模型缺失/低配设备自动回退 v1 纯能量模式 |

可选增强：Vosk 关键词检测（唤醒词式触发）作为 v2.1 评估项。
