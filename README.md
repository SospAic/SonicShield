# 声盾 SonicShield

> 跨平台音频自动化与自我保护工具（Flutter · Android/iOS）
> 定时 / 随机时间 / 随机日期 / 随机时长 / 随机音量 —— 播放音频或执行动作；
> 支持声音触发自动响应、系统级后台执行与精细电源管理。

⚠️ **合规红线**：本应用仅限合法的个人自动化与自我保护用途（定时提醒、助眠/专注音、
习惯养成、对骚扰噪声的**录音取证**、守护提示等）。**严禁用于骚扰、恐吓、报复他人**——
随机时间/随机音量播放声音干扰他人，在多数地区本身即违反《治安管理处罚法》
《噪声污染防治法》等法规。应用内置强制免打扰时段、冷却与完整审计日志，
详见 [docs/08-合规与安全使用白皮书.md](docs/08-合规与安全使用白皮书.md)。

## 功能总览

| 能力 | 说明 |
|---|---|
| 六种触发方式 | 固定一次 / 每日定时 / 每周定时 / **随机窗口**（日期范围×每日N次随机时刻）/ **随机间隔** / 声音触发 |
| 随机化引擎 | 随机时刻、随机日期、**随机时长**、**随机音量**、音源加权随机；**确定性随机**（重启不漂移） |
| 六种动作 | 播放音频 / TTS 播报 / 通知 / **录音取证** / 震动 / 组合（通知+播放） |
| 后台执行 | Android 前台服务 + 精确闹钟双通道（Doze/进程被杀/开机 自恢复）；iOS 后台音频+BGTask+本地通知 |
| 电源管理 | 性能/平衡/省电三档策略；低电量自动降级；电池白名单与厂商保活引导 |
| 声音守卫 | 麦克风能量阈值检测（VAD），可配灵敏度/持续时间/冷却；YAMNet 分类在路线图 v2 |
| 审计与合规 | 全部执行留痕（时间/来源/动作/音量/时长）；免打扰护栏写死不可绕过 |
| 远程遥控 | MQTT over TLS + 端到端加密（配对码派生密钥）的命令/回执/审计；设备状态、定位、音量、振动、任务 CRUD、指令组 |
| 远程桌面级控制 | **受控投屏（看）+ 无障碍输入注入（控）**：MediaProjection 逐次授权 + 系统无障碍开关双授权；会话期端点常驻可见指示且可一键停；权限位 `script`。路线图见 [docs/61](docs/61-远程桌面级控制实施路线.md) |

## 技术栈

Flutter 3.47 (Dart 3.10) · Riverpod · go_router · sqflite · just_audio + audio_session ·
record · flutter_background_service · flutter_local_notifications · TFLite 声音分类(v2 规划)。
选型理由与备选方案对比见 [docs/03-技术架构设计.md](docs/03-技术架构设计.md)。

## 快速开始

```powershell
# 1) 安装 Flutter 3.24+ 与 Android SDK（详见 docs/10-构建发布指南.md）
# 2) 补全平台工程并拉取依赖
.\bootstrap.ps1          # macOS/Linux: bash bootstrap.sh
# 3) 运行
flutter run              # 连接模拟器或真机
# 4) 测试（必须分层：混跑会因压测 CPU 争用假红）
flutter test --exclude-tags perf          # 功能层 2563 例
flutter test --tags perf --concurrency=1  # 压测层 24 例
flutter analyze          # 0 error / 0 warning
# 5) 构建（release 产物固定输出到根目录 releases/，固定文件名）
flutter build apk --release
copy build\app\outputs\flutter-apk\app-release.apk releases\SonicShield-Android.apk
#   iOS：releases\SonicShield-iOS.ipa
# 6) 一键装到所有真实设备（有线 USB + 无线 ADB + iOS）
install_all.bat          # 读 releases\wireless.txt 自动 connect，逐台 install
```

模拟器联测：`scripts\emulator_test.ps1`（安装→静默授权→白名单→启动→日志）。

> **release 产物约定（第八十四轮基线）**：无论 Android / iOS，release 一律落在
> 项目根目录 `releases/`，且用**固定文件名** `SonicShield-Android.apk` /
> `SonicShield-iOS.ipa`（新版本只覆盖同名文件）。一键安装入口 = 根目录
> `install_all.bat`；无线设备地址写在 `releases/wireless.txt`（每行一个 `host:port`）。

## 目录结构

```
lib/
├── core/            常量、主题、路由、确定性随机工具
├── domain/          领域模型（触发/动作/任务）+ 调度引擎（纯函数，可完全单测）
├── data/            sqflite 数据库 + 仓储层
├── services/        播放/声音守卫/通知/电源/原生桥/后台引擎/权限流程
└── features/        六大界面：守护仪表盘/任务/音源/守卫/日志/设置
android/             Manifest（权限+前台服务+接收器）、Kotlin 原生桥与看门狗
ios/                 Info.plist（后台模式/BGTask/麦克风用途声明）
releases/            release 产物固定目录（Android APK / iOS IPA + README + wireless.txt）
install_all.bat      一键装到所有真实设备（有线 + 无线 + iOS）
docs/                全套工程文档（立项/需求/架构/保活/合规/测试/发布…）
```
